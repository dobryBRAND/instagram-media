# instagram-media

Verejné obrázky určené na publikovanie na Instagrame. Meta si ich pri zverejnení sťahuje z adries
`https://raw.githubusercontent.com/dobryBRAND/instagram-media/main/media/<súbor>`.

Patria sem iba hotové publikačné obrázky a videá. Žiadne tokeny, súkromné údaje ani pracovné podklady.
Súbor s rovnakým názvom sa neprepisuje iným obsahom.
